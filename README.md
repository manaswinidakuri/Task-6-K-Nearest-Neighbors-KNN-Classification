Task 6: KNN Classification

 Objective
To understand and implement K-Nearest Neighbors (KNN) for classification.

 Dataset
Iris Dataset

 Tools Used
- Python
- Scikit-learn
- Pandas
- Matplotlib

Steps Performed
1. Loaded dataset
2. Split into train and test
3. Applied StandardScaler for normalization
4. Trained KNN model
5. Tested different K values
6. Evaluated using accuracy and confusion matrix

Results
Best accuracy obtained with K=3.
